# Widescreen research data

These 31 serial/boot-EXE matched files preserve explicitly selected source
entries and all their parts. This directory is not copied into romfs or scanned
by the frontend. It includes negative results: Crash 1 misses edge geometry;
Driver 2 Rev 1 never matches its source original; Final Fantasy VIII requires
battle validation and scene-aware aspect presentation.

Exact code lists, source sections, rights, tests and verdicts are in
`../catalog.json`. Source data is duckstation/chtdb commit
8b2f1dd257ab9130d16b72e0caeb5a07af8bcbdc. Its processing scripts are MIT;
patch/cheat rights remain with the original authors, with no blanket grant
stated. These data files do not claim MIT or CC BY-SA licensing.

A matched serial is only the first filter. A7 known originals, runtime overlay
guards, actual widened gameplay, edge/HUD checks, rollback and console cost
must pass before a record can become a release profile. A cold menu smoke test
or a historical touched count does not establish that the patch is live.
