# PSX3D v0.3.1

- Faster GPU rendering and less repeated screen/audio work, especially on Old 3DS.
- Save-state previews now capture the GPU picture.
- Fixes box art sometimes failing to appear in the Old 3DS library.

Old 3DS still uses GPU by default; New 3DS uses Software. Symphony of the Night
keeps its Software preset on both. Automatic frameskip keeps the same default.

**The GPU renderer is experimental and still has many issues**, including drawing
errors, missing effects and flicker in some games. Switch to Software in the
game's settings when needed. Demanding games can still run slowly on Old 3DS.
